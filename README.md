# Wikipedia Random Article Telegram Bot

Телеграм-бот для получения случайных статей из Википедии на различных языках. Бот позволяет пользователям запрашивать случайные ссылки на статьи Википедии с поддержкой нескольких языков.

## Возможности

- 🎲 Получение случайных статей из Википедии
- 🌍 Поддержка множества языков (настраивается)
- 💾 Сохранение выбранного языка для каждого пользователя
- 🐳 Готовый Docker-образ для быстрого развертывания
- ⚡ Асинхронная архитектура на базе aiogram 3.x

## Требования

- Python 3.11 или выше
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))
- Docker и Docker Compose (опционально, для контейнеризации)

## Установка

### Вариант 1: Запуск с Docker (рекомендуется)

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd wikipedia-telegram-bot
```

2. Создайте файл `.env` на основе `.env.example`:
```bash
copy .env.example .env
```

3. Отредактируйте `.env` и укажите ваш токен бота:
```env
BOT_TOKEN=your_actual_bot_token_here
AVAILABLE_LANGUAGES=ru,en,de,fr
```

4. Запустите бота с помощью Docker Compose:
```bash
docker-compose up -d
```

5. Проверьте логи:
```bash
docker-compose logs -f
```

### Вариант 2: Запуск без Docker

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd wikipedia-telegram-bot
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
venv\Scripts\activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` на основе `.env.example`:
```bash
copy .env.example .env
```

5. Отредактируйте `.env` и укажите ваш токен бота

6. Запустите бота:
```bash
python main.py
```

## Конфигурация

### Переменные окружения

Все настройки бота задаются через файл `.env`:

| Переменная | Обязательная | Описание | Пример |
|------------|--------------|----------|--------|
| `BOT_TOKEN` | ✅ Да | Токен Telegram бота от @BotFather | `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz` |
| `AVAILABLE_LANGUAGES` | ❌ Нет | Список доступных языков через запятую | `ru,en,de,fr` (по умолчанию: `en`) |

### Поддерживаемые языки

Бот поддерживает любые языковые версии Википедии. Используйте двухбуквенные коды языков:

- `ru` - Русский
- `en` - English
- `de` - Deutsch
- `fr` - Français
- `es` - Español
- `it` - Italiano
- `ja` - 日本語
- `zh` - 中文
- `pt` - Português
- `ar` - العربية
- и другие...

Полный список кодов языков: [ISO 639-1](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes)

## Использование

### Команды бота

После запуска бота откройте его в Telegram и используйте следующие команды:

#### `/start`
Приветственное сообщение с кратким описанием возможностей бота.

**Пример:**
```
Пользователь: /start

Бот: 👋 Добро пожаловать в Wikipedia Random Article Bot!

Я помогу вам открывать случайные статьи из Википедии на разных языках.

Доступные команды:
/random - Получить случайную статью
/language - Выбрать язык статей
/help - Показать справку

Доступные языки: ru, en, de, fr
```

#### `/help`
Показывает список всех доступных команд с описанием.

**Пример:**
```
Пользователь: /help

Бот: 📚 Справка по командам:

/start - Приветственное сообщение
/random - Получить случайную статью из Википедии
/language - Выбрать язык для статей
/help - Показать эту справку

Выберите язык с помощью /language, затем используйте /random для получения случайных статей!
```

#### `/random`
Отправляет ссылку на случайную статью Википедии на выбранном языке.

**Пример:**
```
Пользователь: /random

Бот: 🎲 Случайная статья (RU):
https://ru.wikipedia.org/wiki/Квантовая_механика
```

#### `/language`
Показывает список доступных языков с кнопками для выбора. Выбранный язык сохраняется для текущей сессии.

**Пример:**
```
Пользователь: /language

Бот: 🌍 Выберите язык для статей:

Текущий язык: RU

[✅ RU] [EN] [DE] [FR]  <- интерактивные кнопки
```

После выбора языка:
```
Бот: ✅ Язык изменен на: EN
```

### Типичный сценарий использования

1. Запустите бота командой `/start`
2. Выберите предпочитаемый язык с помощью `/language`
3. Получайте случайные статьи командой `/random`
4. При необходимости меняйте язык снова через `/language`

Просто добавьте коды языков в переменную `AVAILABLE_LANGUAGES` в файле `.env`:

Перезапустите бота для применения изменений.

## Обработка ошибок

Бот корректно обрабатывает следующие ситуации:

- **Отсутствие токена**: Бот не запустится и выведет ошибку в лог
- **Проблемы с Wikipedia API**: Пользователь получит сообщение "Не удалось получить статью, попробуйте позже"
- **Таймаут запроса**: Автоматическая обработка с уведомлением пользователя
- **Некорректный язык**: Валидация при загрузке конфигурации

## Технические детали

- **Библиотека**: aiogram 3.x (асинхронная)
- **API**: Wikipedia REST API v1
- **Хранилище состояний**: In-memory (MemoryStorage)
- **Таймаут запросов**: 5 секунд
- **Размер Docker-образа**: ~70-90 MB (Alpine Linux)
