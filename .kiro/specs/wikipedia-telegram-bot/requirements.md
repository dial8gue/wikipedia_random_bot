# Requirements Document

## Introduction

Телеграм-бот для получения случайных статей из Википедии на различных языках. Бот позволяет пользователям запрашивать случайные ссылки на статьи Википедии, поддерживает несколько языков, которые настраиваются через переменные окружения. Реализован с использованием библиотеки aiogram и упакован в минимальный Docker-образ для эффективного развертывания.

## Glossary

- **Bot**: Телеграм-бот, реализованный с использованием aiogram
- **User**: Пользователь Telegram, взаимодействующий с ботом
- **Wikipedia API**: API Википедии для получения случайных статей
- **Language Code**: Двухбуквенный код языка (например, ru, en, de)
- **Environment File**: Файл .env с конфигурационными параметрами
- **Docker Image**: Контейнеризованное приложение бота
- **Inline-кнопка**: Интерактивная кнопка в сообщении Telegram, которая отправляет callback-запрос при нажатии

## Requirements

### Requirement 1

**User Story:** Как пользователь, я хочу получать случайные ссылки на статьи Википедии, чтобы открывать для себя новый контент

#### Acceptance Criteria

1. WHEN User отправляет команду боту, THE Bot SHALL запросить случайную статью через Wikipedia API
2. WHEN Bot получает данные от Wikipedia API, THE Bot SHALL отправить User ссылку на случайную статью
3. IF Wikipedia API возвращает ошибку, THEN THE Bot SHALL отправить User сообщение об ошибке
4. THE Bot SHALL отвечать на запросы User в течение 5 секунд

### Requirement 2

**User Story:** Как пользователь, я хочу выбирать язык статей Википедии, чтобы читать контент на понятном мне языке

#### Acceptance Criteria

1. THE Bot SHALL поддерживать несколько языков для запросов к Wikipedia API
2. WHEN User запрашивает список доступных языков, THE Bot SHALL отобразить все языки из Environment File
3. WHEN User выбирает язык, THE Bot SHALL запрашивать случайные статьи на выбранном языке
4. THE Bot SHALL сохранять выбранный язык User для последующих запросов в рамках сессии

### Requirement 3

**User Story:** Как администратор, я хочу настраивать доступные языки через файл конфигурации, чтобы управлять функциональностью бота без изменения кода

#### Acceptance Criteria

1. THE Bot SHALL читать список доступных языков из Environment File при запуске
2. THE Bot SHALL читать токен Telegram API из Environment File при запуске
3. IF Environment File отсутствует или содержит некорректные данные, THEN THE Bot SHALL записать ошибку в лог и завершить работу
4. WHEN Environment File изменяется, THE Bot SHALL применить новые настройки после перезапуска

### Requirement 4

**User Story:** Как пользователь, я хочу использовать простые команды для взаимодействия с ботом, чтобы быстро получать нужную информацию

#### Acceptance Criteria

1. WHEN User отправляет команду /start, THE Bot SHALL отправить приветственное сообщение с инструкциями
2. WHEN User отправляет команду /help, THE Bot SHALL отправить список доступных команд
3. WHEN User отправляет команду /random, THE Bot SHALL отправить случайную ссылку на статью Википедии
4. WHEN User отправляет команду /language, THE Bot SHALL отобразить список доступных языков и позволить выбрать язык

### Requirement 5

**User Story:** Как DevOps инженер, я хочу развертывать бота в Docker-контейнере, чтобы обеспечить изолированность и портативность приложения

#### Acceptance Criteria

1. THE Bot SHALL быть упакован в Docker Image размером менее 100 МБ
2. THE Docker Image SHALL использовать минимальный базовый образ (alpine или distroless)
3. THE Docker Image SHALL запускать Bot при старте контейнера
4. THE Bot SHALL корректно завершать работу при получении сигнала остановки контейнера

### Requirement 6

**User Story:** Как пользователь, я хочу видеть кнопку "Ещё" после получения статьи, чтобы быстро запросить следующую случайную статью без повторного ввода команды

#### Acceptance Criteria

1. WHEN Bot отправляет User ссылку на случайную статью, THE Bot SHALL добавить inline-кнопку с локализованным текстом
2. WHEN User нажимает на inline-кнопку, THE Bot SHALL отправить новую случайную статью на текущем выбранном языке
3. THE Bot SHALL локализовать текст кнопки в соответствии с выбранным языком User
4. WHEN Bot отправляет новую статью по нажатию кнопки, THE Bot SHALL снова добавить inline-кнопку для продолжения
5. WHEN Bot отправляет User сообщение об ошибке получения статьи, THE Bot SHALL добавить inline-кнопку для повторной попытки
